# iStay Hotels — Modern Business & Leisure Hospitality

Official website and web platform for **iStay Hotels**, a contemporary business and leisure hospitality brand offering smart comfort, authentic dining, and prime city locations across India.

## 🏨 Featured Properties
1. **iStay Hotels Jubilee Hills**, Hyderabad (Active)
2. **iStay Hotels Hitech**, Hyderabad (Active)
3. **iStay Hotels Rajajinagar**, Bangalore (Active)
4. **iStay Hotels ShantaShiva Arcade**, Haveri (Opening Soon)
5. **iStay Hotels Luxe Collection**, Haridwar (Opening Soon)

## 🌟 Key Features
- **Dynamic Bouncing Logo Loading Screen**: Physics-based animated ball loading screen settling on the iStay logo.
- **Cinematic Homepage Hero**: Full-bleed hotel photography with bold typography and floating booking widget.
- **Interactive "Our Hotels" Selector**: State-driven master-detail hotel explorer with responsive desktop split view and mobile swipeable switcher.
- **Dedicated Property Pages**: Full 17-section layout for each of the 5 hotels with accommodations, dining, facilities, attractions, maps, reviews, and direct contact desk.
- **Curated F&B Concepts**: In-depth pages for **Utsavam**, **Moxa Xpress**, **Xtra Grab & Go**, and **Kalpavrixa Restaurant**.
- **Interactive Nearby Attractions Map**: Real coordinate markers, interactive popups, and direction links.
- **Meetings & Events**: Corporate booking request desk with full equipment breakdowns.
- **Masonry Image Gallery**: 15-category photo gallery with high-resolution lightbox modal.
- **Integrated Booking & Enquiry Flow**: Date validations, guest selection popovers, promo code integration, and booking confirmation.

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Routing**: React Router DOM v6

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
